# APXCONFIG

Cofigurador de carro APX
APX Systems

Consiste num programa em C que permite ao vendedor juntamente com o cliente configurar um carro APX, escolhendo o modelo, cor, jantes e janelas.
O programa é interativo e utiliza a biblioteca conio.h para capturar a entrada através do teclado e permitir a navegação pelas opções dos extras.
A biblioteca windows.h é utilizada para definir a codificação de caracteres para UTF-8, permitindo a exibição correta de caracteres especiais.
O objectivo do projeto é usar whiles e ifs para criar menus selectores dos extras, havendo a possibilidade de mudar a escolha das mesmmas e no final motrar o resumo.
O resumo terá uma pequena descrição dos extras escolhidos, e o preço final do carro, prazo de entrega assumindo a peça com mais tempo de entrega mais 2 a 3 dias úteis, 
e a data de entrega assumindo que o carro é encomendado no dia da compra.
No final, o programa dará a confirmação do pagamento e após validação, apresentará uma referência de encomenda básica para simular a compra do carro.
